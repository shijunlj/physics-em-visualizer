圆柱壳的表面电流与磁场

两种理想无限长圆柱薄壳。每幅图可独立拖动旋转、滚轮缩放和移动观察点。

竖直圆柱 · 轴向电流

表面电流密度 j，沿轴向向上

r < R：B = 0
r > R：B = μ₀I/(2πr) = μ₀jR/r

j 是沿圆周每米宽度通过的轴向电流，单位 A/m。均匀分布时，j = I/(2πR)，其中 I 是总电流。

水平圆柱 · 环向电流

沿轴线单位长度的环向电流为 j′，单位 A/m

r < R：B = μ₀j′　　r > R：B = 0
表面电流方向 磁场方向 观察点 P 与该点磁场

图中只截取圆柱的一段。绿色线条表示磁场的方向与所在区域。两图各自归一化，箭头长度不用于跨图比较场强。
